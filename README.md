# M-ELVN Team Mini App

Telegram Mini App для пилотов, менеджеров и руководства картинговой команды M-ELVN.

Как устроено:
- Данные ведут админы в Google-таблице (листы «Люди», «События», «Составы»; строка 1 — заголовки, строка 2 — подсказки).
- Google Apps Script внутри таблицы (`dist/Code.gs`) — это «сервер»: проверяет подпись Telegram (`initData`), находит человека по нику или ID и отдаёт только видимые ему события.
- `public/` — интерфейс приложения, публикуется на GitHub Pages при каждом пуше в `main` (`.github/workflows/pages.yml`). Адрес скрипта — в `public/config.js`.

Видимость: пилот — события, где он в составе (видит все экипажи на них); менеджер — события, где он менеджер экипажа; руководство — всё. Роли складываются.

Разработка:
- Логика — `src/logic.js`, точка входа скрипта — `src/gas-main.js`.
- `npm run build:gas` собирает `dist/Code.gs`; его содержимое вставляется в редактор Apps Script, в `BOT_TOKEN` вписывается токен бота. Обновлять через «Управление развертываниями» → изменить → «Новая версия», чтобы адрес не менялся.
- `npm test` — сборка и тесты (логика + запуск собранного скрипта в песочнице).

Почему не Cloudflare: адрес workers.dev не открывался у команды даже через VPN, а Cloudflare в России часто блокируется.
