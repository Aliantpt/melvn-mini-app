# M-ELVN Team Mini App

Telegram Mini App для пилотов, менеджеров и руководства картинговой команды M-ELVN.

- Данные ведут админы в Google-таблице (листы «Люди», «События», «Составы»).
- `google/apps-script.gs` — скрипт внутри таблицы, отдаёт данные по секретному ключу.
- `src/` — Cloudflare Worker: проверяет вход через Telegram, читает таблицу (кэш 60 с), решает, кто что видит.
- `public/` — интерфейс приложения.

Видимость: пилот — события, где он в составе (видит все экипажи на них); менеджер — события, где он менеджер экипажа; руководство — всё. Роли складываются.

Секреты Cloudflare: `BOT_TOKEN`, `SHEET_URL`, `SHEET_TOKEN`. Часовой пояс — `TIMEZONE` в `wrangler.toml`.

Тесты: `npm test`.
